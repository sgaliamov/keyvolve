# Shared local memory

- Read `.memory/memory.md` and relevant files in `.memory/plans/` when available; verify saved facts against current code and instructions.
- Keep reusable, verified project facts and decisions in `.memory/memory.md`. Update or remove stale notes; don't store secrets.
- Save plans as `.memory/plans/<topic>.md` using a descriptive topic. Update the relevant plan after feedback; don't overwrite unrelated plans.
- `.memory/` is Git-ignored local storage, not any agent's built-in memory. Create files or directories as needed. Don't force-add them to Git.
